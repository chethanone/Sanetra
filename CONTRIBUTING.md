# Contributing to Sanetra

1. Ensure Flutter (`flutter analyze lib test` and `flutter test`) passes with zero issues.
2. Never commit raw datasets, private reviewer images, keystores, `.env` files, or API tokens.
3. Preserve offline-first execution: currency recognition, OCR, flashlight, and TTS must never require network access.
4. Keep the Android package ID `com.visionassistant.vision_assistant.visionmission` unchanged across releases.
